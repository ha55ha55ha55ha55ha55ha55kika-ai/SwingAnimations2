# ClientLink: как подключить

Значок логотипа у ника / в чате / в TAB и плашка «что слушает» работают, когда игроки могут обменяться маленькими пакетами.
Есть два способа, включаются в модуле ClientLink настройкой «Связь» (по умолчанию оба сразу).

## 1. Свой сервер: плагин SwingLinkRelay (Paper 1.21.x)
```
cd extras/SwingLinkRelay
gradle build        # jar будет в build/libs, положить в plugins/
```
Плагин только пересылает пакеты между игроками с модом (с защитой от флуда). Без плагина клиент по каналу ничего не шлёт.

## 2. Чужие серверы: HTTP-реле
На любой машине с Python 3 (Termux подойдёт):
```
python3 extras/swing_relay.py        # порт 8765; SWING_TOKEN=секрет для общего пароля
```
В файле `config/swinganimations_modules.json` у модуля `client_link` пропиши:
```
"relay_url": "http://ТВОЙ_АДРЕС:8765",
"relay_token": "секрет"            // если задавал SWING_TOKEN
```
У всех, кто должен видеть друг друга, должны быть одинаковые relay_url и токен.

Что видят другие: только факт, что ты с клиентом, и название/исполнителя текущего трека (если включено «Показывать, что я слушаю»).
Отключить можно в настройках модуля. Тексты из сети чистятся, а запись принимается только для игроков из списка сервера.

## Как часто клиент шлёт данные (HTTP-реле)
- `POST /hello`: при входе на сервер, затем **каждые 30–45 секунд** (случайный разброс), и сразу при смене трека (не чаще раза в 5 с). Запись на реле живёт 90 секунд, поэтому один пропущенный hello не страшен.
- `GET /peers`: каждые 12–18 секунд (и через 5 секунд после входа), чтобы значки у новых игроков появлялись быстро. Тем, у кого выключено «Share that I use the client», /hello не уходит вовсе, список игроков они всё равно получают.
- Ключ сервера (`server`): адрес из списка серверов в нижнем регистре, без пробелов, конечной точки и порта `:25565`. `Play.Site.com`, `play.site.com.` и `play.site.com:25565` дают одно значение. Разные адреса одного сервера (например, IP и домен) считаются разными серверами, значки между ними не видны.
- На одиночной игре и в LAN запросы не шлются.

## Токен и прокси
- На реле задайте `SWING_TOKEN=секрет`, у клиента тот же токен в `relay_token` (или впишите значения по умолчанию в `ClientLinkModule.DEFAULT_RELAY_URL` и `DEFAULT_RELAY_TOKEN` перед сборкой, чтобы игрокам ничего не настраивать). Токен внутри jar не секрет, он отсекает только случайный спам.
- Если хостинг стоит за прокси, задайте `TRUST_PROXY=1`. Иначе для реле все игроки выглядят как один IP, и общий лимит (30 запросов за 10 секунд) начнёт отвечать 429.
- Если токен неверный, клиент один раз покажет сообщение «реле отклонило токен (403)».
