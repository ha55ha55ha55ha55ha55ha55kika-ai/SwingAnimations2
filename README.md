# SwingAnimations (Fabric 1.21.4, client-only)

1. Скопируйте `gradle/wrapper/gradle-wrapper.jar`, `gradlew`, `gradlew.bat` из https://github.com/FabricMC/fabric-example-mod
   (или выполните `gradle wrapper --gradle-version 8.12`).
2. `./gradlew runClient` для запуска, `./gradlew build` для сборки (jar в build/libs/).
